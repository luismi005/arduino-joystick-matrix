# 🤖 arduino-joystick-matrix
This project controls an 8x8 LED matrix using an analog joystick and an Arduino Uno. Powered by two cascaded SN74HC595 shift register ICs, all 64 LEDs are driven using only 3 digital pins. It includes two scripts for the same setup: pizarra.ino, a drawing tool controlled by the joystick, and snake_game.ino, the classic Snake game.
